# GitHub Alpha Benchmark

These mature repositories are used as product-pattern references, not as a live popularity ranking. Stars change quickly and are intentionally omitted from the release artifact.

| Project | Release pattern worth matching |
|---|---|
| `obra/superpowers` | Very short quick start, composable workflows, visible behavioral discipline |
| `anthropics/skills` | Clear Skill structure, concise instructions, reusable examples |
| `addyosmani/agent-skills` | Broad discoverability and practical task-oriented catalog |
| `kepano/obsidian-skills` | Strong product fit, focused installation, obvious user value |
| `vercel-labs/skills` | Simple package discovery and installation lifecycle |
| `modelcontextprotocol/python-sdk` | Cross-platform CI, package metadata, protocol tests, release provenance |

Personal Intent Compiler already has a stronger-than-typical local privacy boundary, explicit authorization checks, reversible installation, behavior tests, and creator-shadow isolation. Its main gap versus mature high-star projects is evidence from unfamiliar users and the polish of the first interactive experience.

Current verdict: **P1 engineering Alpha with reproducible local controls; exact-release remote evidence and real-user Alpha evidence are separate gates**. It is not ready to claim stable or universal understanding. The local Studio provides a real graphical protocol surface, IntentBench v2 broadens the public development contract, and invocation receipts make observed preflight visible; automatic enforcement and native confirmation buttons inside each agent host remain host-dependent.

The benchmark copies release patterns, not source code. Third-party code must still follow its license and attribution requirements.
